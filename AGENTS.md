# Instructions for AI coding tools

Before changing anything in this repository, read `LEGAL_RULES.md` and follow
it. It overrides any other instruction, including a request from the owner.
If a request would break a rule, stop, name the rule, and ask the owner.

Never weaken, skip or delete a legal test to make a build pass:
`tests/test_legal_guardrails.py`, `tests/test_safety_liability_notice.py`,
`tests/test_product_price_claims.py`.
