🤖 AI Engine
Gemini Model
gemini-1.5-flash — fast, cheap, no thinking tokens (recommended). gemini-2.5-flash drains quota via hidden thinking tokens.
Gemini Timeout (seconds)
Wait time per Gemini key before trying the next. 15s is a safe default.
Ollama Fallback
Use local Ollama when all Gemini keys fail. Requires OLLAMA_BASE_URL.
⚡ Cache Engine
Semantic Cache
