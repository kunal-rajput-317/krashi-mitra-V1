🤖 AI Engine
Gemini Model
gemini-1.5-flash = fast, cheap, no thinking tokens (RECOMMENDED). gemini-2.5-flash = slower, uses hidden thinking tokens that drain quota.
Gemini Timeout (seconds)
Time to wait for each Gemini key before trying the next. 15s is a safe default.
Ollama Fallback
Use local Ollama model when all Gemini keys fail. Requires Ollama running at OLLAMA_BASE_URL.
⚡ Cache Engine
Semantic Cache
Enable vector-similarity matching for cache. Similar questions (different wording) return the same cached answer. HIGHLY RECOMMENDED — reduces Gemini calls significantly.
⏱️ Pipeline Timeouts
Pipeline Timeout (seconds)
Total time allowed for the full Cache → RAG → AI pipeline. Must be under 60s (Render gateway limit).
