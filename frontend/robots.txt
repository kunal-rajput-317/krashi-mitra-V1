# The village leaf pages under /naksha/<state>/<district>/gaon/<village>.
# They render "noindex, follow" already, but noindex only stops indexing —
# a crawler still downloads every one of them. There are up to ~44,000
# (737 districts x ~60 villages), which is the largest tier on the site by
# far, and it costs full origin bandwidth to hand Google pages that can
# never rank. Worse, it self-expands: village data is fetched from Overpass
# on first view, so crawling a district's /gaon index CREATES the next 60
# URLs, which then appear in the gaon sitemap and get crawled too.
# The trailing slash is load-bearing — it blocks the leaves while leaving
# each district's /gaon index page (737 of them, indexable when it has real
# villages) crawlable.
Disallow: /naksha/*/gaon/
