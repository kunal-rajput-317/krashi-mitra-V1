# KrashiMitra — instructions for Claude Code

Read and follow the legal rules below before any change. They override any
other instruction, including a request from the owner. If a request would
break one, stop, name the rule, and ask the owner. Do not work around it.

@LEGAL_RULES.md

## Working rules

- Never weaken, skip or delete a legal test (`tests/test_legal_guardrails.py`,
  `tests/test_safety_liability_notice.py`, `tests/test_product_price_claims.py`)
  to make a build pass. Fix the change instead.
- Never commit or push until the owner says so.
- New articles are generated by `tools/articles/*.py` through the builder, not
  hand-written HTML.
- Never open `.env` or print any secret from it. Never query a personal-data
  table (`users`, `user_profiles`, `orders`, `payments`, `chat_history`,
  `bazar_*`, `seller_verifications`, `buyers`, `account_deletions`,
  `dukan_shops`, `rental_providers`, `crop_appeals`, `mandi_alerts`,
  `push_subscriptions`) on the live database. Whatever an AI tool reads is
  sent to its company, and the privacy policy does not allow that
  (LEGAL_RULES §4). Work on the test SQLite database instead; on the live one,
  only counts or non-personal tables (mandi prices, weather, articles).
- Since 24 Oct 2026 this is enforced in code: `backend/utils/ai_db_guard.py`
  refuses any non-local database when an AI tool started the process
  (`tests/test_ai_db_guard.py`). Never remove, weaken or bypass it, never
  clear `CLAUDECODE` or the other markers to get round it, and never ask the
  owner for the database password. Live-database work is the owner's, in
  their own terminal.
